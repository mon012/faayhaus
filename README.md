# FAAY HAUS Astro

Static brand and editorial product catalog for `faayhaus.com`.

## Commands

```sh
npm install
npm run dev
npm run build
```

Deploy the generated `dist/` directory with Cloudflare Pages. Build command:
`npm run build`; output directory: `dist`.

The site has no cart, account, checkout, or payment flow. Product actions open
the corresponding Amazon listing. Source content and media are copied into this
repository so the production build does not depend on WordPress.
